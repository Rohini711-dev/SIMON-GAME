# Simon Game - Interactive Memory Game

Browser-based memory game built with vanilla JavaScript to replicate the classic Simon electronic game.

##  Live Demo
[Play Game](https://your-github-pages-link-here)

##  Tech Stack
- **Frontend**: JavaScript ES6+, HTML5, CSS3
- **Concepts**: DOM Manipulation, Event Listeners, Arrays, Game State Management

##  Features
- Uses **arrays** to generate and validate color sequences
- **Event-driven programming** for user interaction and game flow
- **DOM manipulation** for real-time UI updates and animations
- Progressive difficulty: sequence increases each round
- Sound effects and visual feedback

##  What I Learned
- Managing complex game state with JavaScript arrays
- Asynchronous timing with setTimeout for game sequences
- Handling user events and validating input against patterns
- CSS animations for responsive UI feedback

##  Run Locally
Just download and open `index.html` in any browser. No installation needed.
